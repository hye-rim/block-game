# 블록 채우기 🟧

블록을 끌어서 10×10 판에 놓고, 가로나 세로 한 줄을 꽉 채워 지우는 퍼즐. [작은 오락실](https://github.com/hye-rim/smallgame)의 게임 중 하나. 의존성 없는 정적 게임(`index.html` + `logic.js` + `game.js`)입니다.

- 아래 블록 3개를 **끌어서** 판에 놓는다 (폰에서는 손가락 위에 떠서 가려지지 않는다). 놓을 자리는 반투명으로, 지워질 줄은 반짝여서 미리 보인다
- 가로·세로 한 줄이 꽉 차면 지워진다. 가로와 세로가 동시에 완성되면 한꺼번에 지운다
- 블록은 돌릴 수 없고, 3개를 모두 놓으면 새 블록 3개가 나온다. 주어진 블록을 어디에도 놓을 수 없으면 끝
- 점수: 놓은 칸 수 + 줄 보너스(1줄 10, 2줄 30, 3줄 60, 4줄 100 …) + 연속으로 줄을 지우는 콤보 보너스
- 판이 빽빽해지면 큰 블록이 덜 나오고, 새 블록 3개 중 적어도 하나는 항상 놓을 수 있다
- 진행 중인 판은 자동 저장되어 이어서 할 수 있다. 최고 점수는 `blockBest`
- PC: 마우스로 끌기, P 일시정지 · M 소리

판 규칙은 `logic.js`(화면 없이 Node 로 시험할 수 있다), 화면·입력은 `game.js`.
